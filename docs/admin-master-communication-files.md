# Allegati delle comunicazioni: correzione, recupero ed esiti

Queste funzioni riguardano i file caricati in un contesto di comunicazione e le annotazioni delle fonti ricevute. Richiedono l’account Admin e l’accesso corrente al contesto. L’autorità nativa sulle comunicazioni resta necessaria per caricare, revocare o creare versioni.

## Correggere o recuperare un file
1. Apri Comunicazioni nel lead, cliente, pratica o conversazione interessati. Segui **Gestisci fonti, versioni e file revocati** oppure il collegamento alla fonte di un allegato.
2. Dalla fonte apri **Versioni e recupero**. Controlla file, stato e contesto originali.
3. Per una correzione indica il nuovo nome e la riservatezza; scegli un nuovo contenuto solo se necessario. Per recuperare un file revocato scegli il recupero dei byte conservati.
4. Conferma la destinazione. La ricerca mostra soltanto contesti ammessi all’account corrente; lo spostamento riguarda la nuova versione.
5. Inserisci il motivo, verifica il riepilogo e registra. Se la conferma privilegiata è scaduta, riconferma nello stesso modulo e premi nuovamente il comando: file e scelte rimangono disponibili.
6. Apri la versione registrata e, se deve essere usata in una comunicazione, selezionala espressamente nella bozza.

Il sistema conserva il file originale e la sua revoca. Una versione disponibile sostituita viene revocata; recuperare un file revocato crea un’identità distinta. Gli allegati nelle comunicazioni già preparate non vengono sostituiti automaticamente. Le approvazioni e le scadenze dei singoli invii mantengono i propri controlli.

## Se una risposta viene interrotta
Conserva il riferimento del tentativo. **Verifica esito** legge la ricevuta e i dati persistiti senza ripetere il comando. La pagina conserva il riferimento nell’indirizzo anche dopo la riapertura. Se il comando non è stato applicato, la chiusura esplicita del tentativo blocca anche un suo eventuale arrivo tardivo; poi puoi preparare una nuova operazione.

Nell’editor di versione è possibile riprendere lo stesso comando finché il modulo conserva ancora il file selezionato. Dopo una ricarica il browser non conserva i byte locali: verifica o chiudi il tentativo prima di una nuova scelta. Un logout o la perdita dell’accesso al contesto richiedono nuovamente un accesso ammesso; la conferma privilegiata non sostituisce i permessi.

## Fonti ricevute e rettifiche
Nella risposta ricevuta o nelle impostazioni delle comunicazioni apri **Fonte e rettifiche**. Puoi consultare l’originale e registrare una rettifica motivata. Testo, mittente, hash, data e collegamenti originali rimangono prove storiche: l’annotazione non riscrive l’email e non prepara un invio.

## Limiti espliciti
- File massimo 20 MiB; contesto massimo 100 file e 200 MiB, compresi quelli revocati. Il recupero non elimina byte storici per liberare quota.
- Le conversazioni interne richiedono la partecipazione corrente anche per un altro Admin. Non vengono aggiunti partecipanti o concessioni.
- I percorsi per commerciali e tecnici mantengono la disponibilità e i download ammessi dal contesto; non ereditano gli editor Admin.
- Il blocco, l’archivio e il ripristino della risposta ricevuta sono descritti nel percorso successivo di [gestione degli stati operativi](admin-operational-lifecycle.md); la fonte ricevuta e le sue prove restano conservate.
- La registrazione di file o rettifiche non invia messaggi. Nessun invio reale è parte delle prove di questa modifica.
